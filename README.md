# India Region IPTV

A community-maintained, India-focused M3U playlist of channel stream URLs. The list is curated by filtering for Indian-region channels and keeping links that were selected as working when checked. Stream status can change, so inclusion is not a guarantee of continuous availability.

This project takes inspiration from the organization and documentation style of [iptv-org/iptv](https://github.com/iptv-org/iptv). It is an independent project and is not affiliated with or endorsed by iptv-org.

## How to use

Copy the playlist URL into a compatible IPTV player such as VLC or Kodi.

**GitHub Pages URL:** https://offorodo.github.io/Ind_regionIPTV/index.m3u

GitHub Pages must be enabled for this repository (Settings → Pages → Deploy from a branch → `main` / `/(root)`). Once Pages finishes deploying, the URL above will serve the playlist in the same style as `https://iptv-org.github.io/iptv/index.m3u`.

## Curation and sources

- The playlist contains stream URLs, not video files. Playback is delivered by the third-party servers named in each URL.
- Links are selected for Indian-region channels and checked for playback when curated; streams may later become unavailable, move, become geo-restricted, or change their terms.
- Channel names and stream metadata are included for identification. An OnnetSystems entry without reliable channel metadata is labeled with its stream ID rather than an invented channel name.
- Some OnnetSystems entries require the HTTP User-Agent option included in the playlist.
- Some source servers provide HTTP rather than HTTPS URLs. These are retained as supplied and may be blocked by players or networks that require secure connections.
- A signed, time-limited WOW Kidz URL was not included because it contained an expiring access token.
