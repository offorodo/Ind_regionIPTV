# India Region IPTV

A curated M3U playlist using the stream links selected for this repository.

## Playlist

- **Raw M3U:** https://raw.githubusercontent.com/offorodo/Ind_regionIPTV/main/india.m3u
- **Repository file:** https://github.com/offorodo/Ind_regionIPTV/blob/main/india.m3u

## How to use

Copy the raw M3U URL into a compatible IPTV player such as VLC or Kodi.

## Notes

- Stream availability can change; links may stop working or be region-restricted.
- Some OnnetSystems entries need the included HTTP User-Agent option.
- OnnetSystems entries whose source metadata did not identify a channel are labeled by stream ID rather than guessing a channel name.
- HTTP-only sources are retained as supplied and may not work in players that block insecure streams.
- A signed, time-limited WOW Kidz URL from the source file was excluded because it contains an expiring access token.
- This repository republishes the selected stream URLs supplied for this playlist. Confirm that you have the rights and permissions required for any redistribution in your jurisdiction.
